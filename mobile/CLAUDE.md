# mobile

**Phase 1 done** (2026-11-18), moved to Flutter 3.50.0 through FVM on 2026-11-20. Skeleton with theme, router, localisation and tests.

The r16a-stream mobile client for Android and iOS. Flutter 3.50.0 with Dart 3.14 through FVM, pinned in `mobile/.fvmrc` (DECISIONS 068), Riverpod, go_router, later dio and `video_player`. App id `cloud.r16a.stream` for now. Architecture in `docs/SPEC.md` section 12.

## Rules specific to this folder

- Run Flutter and Dart only through FVM, `fvm flutter ...` and `fvm dart ...`, after `fvm install` in this folder. Never use or upgrade the shared SDK at `~/development/flutter`, Zaltys depends on it. The version changes only in `.fvmrc`, and CI (`.github/workflows/mobile.yaml`) follows it.
- Checks are `fvm flutter pub get && fvm flutter analyze && fvm flutter test`, and `fvm dart format lib test`.
- Material and Cupertino come from `package:material_ui/material_ui.dart` and `package:cupertino_ui/cupertino_ui.dart`, never `package:flutter/material.dart` or `cupertino.dart`, which Flutter 3.50 deprecates. Import `flutter_localizations` with `show GlobalWidgetsLocalizations` only, its other delegates clash with the new packages (DECISIONS 069).

- Feature code in `lib/features/<home, favorites, lists, title, player, requests, settings>/`, cross-cutting code in `lib/core/`, reusable widgets in `lib/core/ui/`. No admin area on mobile.
- Logic in Riverpod notifiers and providers. Screens read providers with `select` to keep rebuilds narrow. Small widgets take values and callbacks and are `const` where possible.
- Navigation only with `context.go()` and `context.pop()`.
- Tokens only in `flutter_secure_storage`. Theme and UI language in shared preferences. Nothing secret in preferences. Android backups off.
- Auth is Authorization Code with PKCE in the system browser through `flutter_appauth`. Debug builds use the `r16a-stream-mobile-dev` provider and scheme `cloud.r16a.stream.dev`, profile and release builds `r16a-stream-mobile` and `cloud.r16a.stream`. The scheme is fixed per build type in `android/app/build.gradle.kts` and `ios/Flutter/*.xcconfig`, `R16A_OIDC_PROFILE` defaults to match and may only be overridden to the same value. Pass `--dart-define=R16A_AUTHENTIK_URL=https://<authentik>` and `R16A_API_BASE_URL`.
- Auth code is in `lib/core/auth/`. `TokenManager` is plain Dart over two interfaces (`OidcClient`, `TokenStore`), so the single-flight refresh is tested with fakes in `test/fakes.dart`. `AuthController` is the Riverpod state the router redirects on.
- `/me` is read as a map for two fields until `swagger_parser` models exist (Phase 3), the only hand-read API shape. Replace it then.
- Authentik rotates refresh tokens on every use. Refresh is single-flight, and the new refresh token is stored before the new access token is used.
- API models are generated by `swagger_parser` from `docs/openapi.json` into `lib/core/api/generated/`, committed, and regenerated only with `shared/scripts/gen-mobile-api.sh`. Never edit them by hand.
- The dio client adds the bearer token, refreshes once on 401 with a single-flight lock, and signs out when refresh fails. It never follows redirects.
- Android backups are off (`allowBackup`, `fullBackupContent`, data extraction rules). Gradle 9.5.0, AGP 9.3.1 and Kotlin 2.4.20 as the Flutter 3.50 template (DECISIONS 073).
- Subtitles are separate WebVTT files loaded into `video_player`. Language switch replaces the controller and seeks to the same position.
- Images decode at display size and cache on the object key, never the presigned URL.
- No hard-coded user-facing strings. ARB files in `lib/core/i18n/arb/` for en, it, es, de, generated with gen-l10n into `lib/l10n/generated/` (committed, regenerated by `flutter pub get` or `flutter gen-l10n`).
- `intl` is pinned to what the SDK's `flutter_localizations` pins (0.20.3 on 3.50.0).
- Colours from `lib/core/theme/tokens.g.dart`, generated from `packages/design-tokens`. Never edit it by hand.

## App id and base URL

The app id lives in `android/app/build.gradle.kts` (`applicationId`), the iOS project (`PRODUCT_BUNDLE_IDENTIFIER`) and the redirect scheme. Rename steps in `docs/OPERATING.md` section 9. The API base URL comes from `--dart-define=R16A_API_BASE_URL`.

## Gotchas (from Zaltys, expected to apply)

- iOS cannot be compiled on this machine (no macOS). iOS-specific files need a check in Xcode.
- Release builds need a real signing key before publishing.
