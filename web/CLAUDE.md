# web

**Phase 2 done** (2026-11-20). Shell, theme, i18n, nginx with the CSP, API types, CSP check, sign-in through the BFF.

The r16a-stream web client. Angular 22.2, TypeScript 6.0, standalone, signals, zoneless, OnPush, SCSS, Vitest through the Angular CLI. Served by nginx with a strict CSP. Architecture in `docs/SPEC.md` section 11.

## Rules specific to this folder

- Node 26.13.1. Install with `npm ci` at the repo root, not here.
- Angular is pinned exactly (framework 22.2.6, CLI and build 22.2.7), TypeScript 6.0.3 (DECISIONS 064).
- The dev proxy is `proxy.conf.mjs`, which strips `Cookie` and `Authorization` on the bucket paths (DECISIONS 061).
- `src/app/core/api/schema.d.ts` is generated by `npm run gen:api` from `docs/openapi.json`. openapi-typescript runs on TypeScript 6 through a root `overrides` entry (DECISIONS 062).
- Every component is OnPush, every route lazy. hls.js is imported only under `player/`.
- Feature folders `home/`, `favorites/`, `lists/`, `title/`, `player/`, `requests/`, `settings/`, `admin/`. Cross-cutting services in `core/`, presentational components in `shared/`, layout in `shell/`.
- Never use `innerHTML`, `bypassSecurityTrust*`, inline scripts, inline event handlers or runtime-built `style` strings. CSP and Trusted Types block them in production even though `ng serve` does not.
- No hard-coded user-facing strings. Everything goes through Transloco keys present in all four language files.
- Colours only from semantic tokens in `packages/design-tokens`. No raw colours.
- Filters and sort live in the URL query string. Lists use keyset cursors and infinite scroll.
- The admin guard is UX only. The API enforces admin rights.
- API types come from `docs/openapi.json` through `openapi-typescript`. Never hand-write a DTO type.
- Sign-in is a full-page navigation to `/api/v1/auth/login?returnTo=`, never an XHR. The session is an HttpOnly cookie, scripts never see it. `SessionService` knows only what `/api/v1/me` answers, and full-page navigation goes through the `NAVIGATOR` token so tests can replace it.
- Routes that need a user take `authGuard`. A 401 from any API call except `/me` sends the user to `/signin?returnTo=` through `unauthorizedInterceptor`. The BFF sends failed logins to `/signin?error=failed` or `error=denied`, and the guard uses `error=unavailable` when the API cannot be reached.

## i18n, supported ICU subset

The custom `IcuSubsetTranspiler` (`core/i18n/`) supports exactly this. Anything else fails at load with an error naming the key.

```
Hello {{name}}                                   Transloco interpolation
{count, plural, =0 {No titles} one {# title} other {# titles}}
{kind, select, movie {Movie} show {Show} other {Title}}
{count, plural, one {{kind, select, movie {# movie} other {# show}}} other {# items}}   nesting
```

- Plural categories come from `Intl.PluralRules(locale)`. Exact matches `=n` win over categories. `#` is the number formatted with `Intl.NumberFormat(locale)`.
- Apostrophe quoting follows ICU (`''` is a literal apostrophe, `'{'` a literal brace).
- Not supported: `selectordinal`, number and date skeletons, `offset:`. Format dates and numbers in code with `Intl`.
- No `eval`, no `new Function`, no generated code. Messages parse once into an AST and are cached per language.

## CSP

Per-response nonce from nginx in the header and in `ngCspNonce`, `index.html` is `no-store`, critical CSS inlining off, theme set by external `theme-init.js`. `media-src 'self' blob:` because hls.js uses MediaSource. hls.js runs with `enableWorker: false`. Check with `npm run check:csp` against the nginx container, because `ng serve` sends no CSP.

## Gotchas

- `ng serve` listens on `localhost`, which resolves to `::1`. Use http://localhost:4200, not 127.0.0.1.
- npm 11.20 blocks dependency install scripts by default. `lmdb` and `msgpackr-extract` from the Angular build tools are left unapproved and fall back to JavaScript.
- Playwright 1.65.1 needs Chromium build 1255 (`npx playwright install --only-shell chromium`).

From Zaltys, expected to apply

- Every nginx `location` that adds a header must include the shared security headers snippet, because `add_header` in a location drops inherited headers.
- The nginx template is rendered with envsubst. Give every new variable an `ENV` default in the Dockerfile.
- A service that adds listeners to `document` or `window` removes them through `DestroyRef`, or Vitest workers leak them across spec files.
